Deep Learning Model

Five-layer DNN with 512→256→128→64→32 neurons, training for 50 epochs on UNSW-NB15 dataset for binary classification.

CSV File Prediction

Upload any UNSW-NB15 formatted CSV and receive per-row predictions with confidence scores in seconds.

Classification Metrics

Comprehensive evaluation metrics: Accuracy, Precision, Recall, F1-Score, and ROC-AUC with visual Confusion Matrix and ROC Curve plots.

Feature Selection

Extra Trees algorithm ranks 42 available traffic features and selects the top 8 most important features using training data.

Robust Preprocessing

Training-fitted encoders, MinMax normalization, missing-value imputation, and a fixed 0.50 decision threshold.

Localhost Only

Runs entirely on your machine — no cloud, no Docker, no external dependencies beyond the Python packages in requirements.txt.
